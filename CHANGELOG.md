# История изменений 1C-telemetry

## Unreleased — 18.11.2026
- Уточнение владельца: только прямой POST файла, без блочной передачи, отдельного регистра загрузок, дополнительных маршрутов или автоматических повторов. Заказчик самостоятельно делит большие файлы при необходимости. Контракт результата упрощён до шести полей. Предыдущая проектная идея блоковой передачи отменена до реализации.
- Убран конфигурационный предел общего размера файла. Первоначально предложена блочная передача 2–3 ГиБ (отменена следующим уточнением); простой POST сохранён. Зафиксирован контракт структурированных результатов BSL и HTTP ошибок, включая неопределённый исход и идемпотентность блоков. Реализация/приёмка пока NOT_RUN.
- Инициализация проекта, описание архитектуры, ТЗ, API v1, правила разработки, безопасности, авторства и выпуска ZIP.
- Проектируемые функции: два расширения, хранение неизменённого JSON и файлов, X-Token, HTTPS, примеры скриптов, штатное расписание заказчика.
- Реализация, сборка ZIP/CFE, BSL LS, CheckConfig, установка и E2E: NOT_RUN / NOT_IMPLEMENTED. Релизов нет.

При каждом выпуске добавлять в начало новый раздел (дата, версии обоих расширений, изменения, точные ссылки на ZIP и хеши, результаты проверок и ограничения). Не переписывать старые релизы.
