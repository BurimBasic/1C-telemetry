Приём телеметрии

Задайте каталог и лимит JSON константами расширения. Публикуйте только HTTP-сервис ТЛМ_ПриемДанных по HTTPS.

В карточке клиента вручную задайте непустой уникальный токен, например 123, и разрешите приём. В настройках отправителя укажите ту же строку. Чтобы заблокировать приём, снимите флаг. После смены токена обновите настройку отправителя.

GET ping проверяет доступ. POST json сохраняет текст UTF-8, POST file принимает бинарное тело. X-Token обязателен. Историю открывайте в штатных списках регистров. Даты записаны в UTC.

В списке «Полученные файлы» выберите запись и нажмите «Скачать файл». Новые файлы лежат в подкаталогах UUID и сохраняют исходное имя. Колонка «Путь к файлу» показывает путь внутри каталога приёма.

Резервируйте ИБ и каталог вместе. При аварии проверьте путь в регистре по UUID файла.
