Отправка телеметрии

Откройте «Функции для технического специалиста» → «Константы» и найдите настройки по префиксу ТЛМ_. Установите адрес корня HTTPS-сервиса, токен и при необходимости путь к публичному PEM. Если таймаут не задан, применяется 60 секунд.

Если публикация сервера требует HTTP Basic, заполните имя пользователя и пароль сервера телеметрии и включите использование авторизации. Токен проверяется при любом режиме.

Для ручной проверки откройте «ТЛМ_Проверка телеметрии» в разделе «ТЛМ_Клиент телеметрии». Нажмите «Проверить подключение», вставьте текст в поле «Тело JSON» и нажмите «Отправить JSON». Для файла сначала нажмите «Выбрать файл», затем «Отправить файл». Версия показана при открытии формы. HTTP-код, UUID или описание ошибки отображаются в результате последней операции.

Версия = ТЛМ_Клиент.Версия();
Итог = ТЛМ_Клиент.ПроверитьПодключение();
Итог = ТЛМ_Клиент.ОтправитьJSON("{""status"":""ok""}");
Итог = ТЛМ_Клиент.ОтправитьФайл(ПутьКФайлу);

Вызывайте методы в серверном BSL. Файл и PEM доступны процессу 1С. Каждый файл отправляется одним POST. При состоянии НЕИЗВЕСТНО сначала проверьте историю.
